# 表单分类编码字典（01 表单）— 后勤/物业工单四级分类

> 定位：后勤/物业管理工单的分类编码唯一权威字典。编码体系为四级「**大类 → 中类 → 小类 → 细类**」，顶部大类以 `01` 前缀代表**表单**类单据，为后续其他单据类型（`02`、`03`…）预留扩展空间。
> 适用场景标记：（医）= 医院专属；（商）= 商场/写字楼/园区专属；无标注 = 通用。

## 编码规则

| 层级 | 位数 | 构成 | 示例 |
|---|---|---|---|
| 大类 | 2 位 | 单据类型前缀，`01` = 表单 | `01` 表单 |
| 中类 | 4 位 | 大类 2 位 + 2 位序号 | `0101` 报修维修 |
| 小类 | 6 位 | 中类 4 位 + 2 位序号 | `010101` 强电维修 |
| 细类 | 8 位 | 小类 6 位 + 2 位序号 | `01010101` 照明/应急照明故障 |

> 层级映射说明：原三级「大类 / 中类 / 细类」加入前缀后整体下移一级——原大类 → 现中类，原中类 → 现小类，原细类 → 现细类；层级名即「大 / 中 / 小 / 细」。

规则约定：

1. 编码一律按**字符串存储**，保留前导零。
2. 已发布编码**只停用、不复用**，保证历史工单可追溯；新增条目在所属父类下顺延。
3. 如需"其他"兜底细类，建议统一使用尾号 `99`，不占用正常序号。
4. `parent_code` 取编码前缀即可关联上级（细类 → 前 6 位，小类 → 前 4 位，中类 → 前 2 位）；查询某小类下全部细类直接 `code LIKE '010101%'`。

## 字典表建议字段

`code`（字符串，保留前导零）、`name`、`level`（1 大类 / 2 中类 / 3 小类 / 4 细类）、`parent_code`（取编码前缀）、`sort`、`status`（启用/停用）、`scene`（通用/医院/商写）、`default_sla`、`default_team`。

- 本清单为**平铺冗余格式**（每行一个细类、四级编码/名称同行），适合整表导入与筛选；入库时可按编码前缀拆成单表自关联字典。
- 医院与商写项目按 `scene` 过滤各自的可见分类，同一套编码两端复用。
